Drop-in Replacement

Fully compatible with standard OpenAI SDKs. Change your base URL and API key, and you're ready.

integration.ts 
import { OpenAI } from 'openai';

 // Simply point to Models.one gateway
const client = new OpenAI({
  baseURL: 'https://api.models.one/v1',
  apiKey: process.env.MODELS_ONE_API_KEY,
});

const response = await client.chat.completions.create({
  model: 'anthropic/claude-3-opus', // Access any model
  messages: [{ role: 'user', content: 'Initialize core systems.' }],
});
